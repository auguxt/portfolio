# 📰 newsroom

> My second portfolio — built with a vintage newspaper aesthetic.

Live at **[auguxt.github.io/newsroom](https://auguxt.github.io/portfolio)**

---

## About

A single-page HTML portfolio styled as a broadsheet newspaper. No frameworks, no build tools — just HTML, CSS, and vanilla JavaScript.

Designed as an upgrade to [auguxt.github.io](https://auguxt.github.io), with a bolder editorial look and richer content layout.

---

## Features

- 🗞️ Newspaper masthead with live date & ticking timestamp
- 📋 Two-column editorial layout (lead story + sidebar)
- 🛡️ Skills Index, Academic Notices & Career Timeline
- 🔲 Featured Projects grid with tech tags
- 🎓 Certificates section
- 💬 Rotating motivational quotes band
- 🎮 Rock Paper Scissors game with score persistence
- 📬 Connect Now contact box
- 📄 Resume download link
- 📱 Fully responsive

---

## Tech Stack

| Layer | Detail |
